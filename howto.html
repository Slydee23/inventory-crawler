Quick guide

  1. Close the game completely. If it is still running it may overwrite your edited file.
  2. Copy your save (SaveProfile0.save) from the game folder to a place you can reach — see your platform below.
  3. Open it in the editor and click Download original (backup) first. Keep that file safe.
  4. Make your changes and click Download edited save.
  5. Check the file name: it must be exactly SaveProfile0.save. Browsers sometimes add a number, e.g. SaveProfile0 (1).save — rename it.
  6. Copy it back into the game folder, replace the old file and start the game.

Something wrong? Copy your backup back (renamed to SaveProfile0.save) and everything is as before.

Which files?

SaveProfile0.saveYour progress: gold, characters, power-ups, relics, cards, gems, unlocks. This is the file you edit most of the time. (Other save slots would be SaveProfile1.save, SaveProfile2.save.)
SettingsData.saveGame options (volume, display, controls). Can be edited too.

Both are text files with a checksum. The editor recalculates the checksum automatically — editing them by hand will make the game reject or reset them.

Android

The saves are in the game's app folder:

Internal storage / Android / data / com.poncle.vampirecrawlers / files / Save /

The catch: since Android 11, normal file manager apps are no longer allowed to write into Android/data. You can often see the folder but not paste into it. Use one of these ways:

A) USB cable + PC — recommended, works on every phone
  1. Connect the phone by USB and choose File transfer on the phone.
  2. On the PC open the phone → Internal storage → Android → data → com.poncle.vampirecrawlers → files → Save.
  3. Copy SaveProfile0.save to the PC, edit it here, then copy the edited file back and replace the old one.
B) On the phone with Shizuku (no root)
  1. Install Shizuku and start it via Wireless debugging (Developer options) — the app guides you. After every phone restart it has to be started again.
  2. Install a file manager with Shizuku support (e.g. ZArchiver, MiXplorer or Material Files) and allow Shizuku access.
  3. With it you can copy files out of and back into Android/data/com.poncle.vampirecrawlers/files/Save.
C) Rooted phone

Any root file manager can read and write the folder directly.

Other options

On some phones and Android versions the system's own Files app can still open Android/data. This depends on manufacturer and version — usually no longer possible on Android 14 and newer.

PC / Steam

The saves are here:

%USERPROFILE%\AppData\LocalLow\Nosebleed Interactive\Vampire Crawlers\Save\

  • Paste the path into the Windows Explorer address bar (AppData is hidden otherwise).
  • Steam Cloud: close the game before copying the edited file back. If Steam asks about a cloud conflict, keep the local files — otherwise your edited save gets replaced by the cloud copy.

iPhone / iPad

The editor works in Safari: tap Choose file, pick the save in the Files app; edited files land in Files → Downloads.

How to get the save out of the game and back on iOS is not known yet — if you know a way, please tell us.

Consoles

Switch, Xbox and PlayStation do not give access to save files, so they cannot be edited.

Troubleshooting

The game ignores my changes
The game was probably still running and overwrote the file — close it completely and copy the file again. Also check the file name (exactly SaveProfile0.save).
The editor says "Checksum invalid"
The file was changed outside the editor. Downloading it from the editor writes a correct checksum again.
A character / power-up / relic doesn't show up
Most content needs its unlock as well. The editor sets both when you use the checkboxes in the category tabs; when editing the Achievements tab directly, only the unlock is set.
Something broke
Copy your backup back. Please report problems on GitHub with a short description.
